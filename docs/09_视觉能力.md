# 她能"看到"你：通话窗口视觉

## 这是什么

视频通话时，对方的画面已经显示在电脑的 QQ 通话窗口里。这个功能让 `call_loop`
在你说出「看看我 / 我什么表情 / 我在做什么动作」时，**截下 QQ 通话窗口**
（而不是整块屏幕）交给视觉模型，让她像真的在看人一样回应你的表情和动作。

好处：

- 不需要额外开摄像头，不占用 `CameraEmulator`（她的虚拟形象照常推流）
- 不需要人脸识别/姿态模型的额外依赖，直接用多模态模型读图
- 窗口被其他窗口遮挡时用 `PrintWindow` 抓，抓不到再退全屏

## 触发方式

只在你明确要求时看，不做无提示的持续截图。

| 话里出现 | 行为 |
|---|---|
| 看、屏幕、画面、图、样子、长得 | 抓 1 帧 |
| **表情、动作、手势、姿势、我在干嘛、我帅吗、我笑了吗** | 抓 1 帧 |
| 动作类词 + `motion_frames=2`（默认） | 间隔约 1 秒抓 **2 帧**，让模型比较动作变化 |

示例：

```
你：你看看我，我今天什么表情？
（她看一眼通话窗口，再回你）
```

## 配置

`config.json` → `llm`：

```json
"vision": {
  "base_url": "https://api.deepseek.com/v1",
  "model": "deepseek-flash",
  "key_env": "DEEPSEEK_API_KEY"
},
"capture": {
  "use": "vision",
  "source": "call_window",
  "max_width": 1280,
  "quality": 70,
  "motion_frames": 2,
  "timeout": 8
}
```

| 键 | 说明 |
|---|---|
| `llm.capture.use` | `vision` = 用 `llm.vision`（DeepSeek，读图已验证、更稳）；`screen` = 用 `llm.screen`（DashScope qwen3-vl-plus，原「看屏幕」路径） |
| `llm.capture.source` | `call_window`：优先截 QQ 通话窗口；`screen`：直接截全屏 |
| `llm.capture.max_width` | 截图缩到多宽再压 JPEG（越大越清楚、token 越多） |
| `llm.capture.motion_frames` | 动作类问题抓几帧 |
| `features.vision_call` | 关掉后完全不截图 |

## 依赖与限制

- 依赖 `pywinauto`（项目里 `call_agent` 已经在用）与 Pillow，无需新装包
- **只在视频通话时有用**：语音通话没有你的画面，截出来的是桌面
- QQ 通话窗口不能最小化；最小化时退化为「截全屏」，可能看不到你的脸
- 视觉模型看不到"你手里的文字"，只能描述画面；要求高精度可换 `qwen3-vl-plus`
- 多帧会多花 token；长对话里建议只在动作/表情类问题触发

## 隐私

- 截图只在通话中、且你明确说了视觉触发词时发生
- 图片只发往你自己配置的视觉模型接口，**不落盘**
- 关闭方式：`features.vision_call: false`，或直接不把 `llm.capture` 配进 config

## 排查

| 现象 | 先查 |
|---|---|
| 她答"看不到你" | 日志有没有 `[看了一眼通话窗口…]` 行；窗口标题是否含「通话」 |
| 截到的是桌面 | 通话窗口最小化了，或 `llm.capture.source` 配成了 `screen` |
| 视觉回复很慢 | 换 `llm.capture.use: "vision"`（DeepSeek 通常比 qwen-vl 快）；或调小 `max_width` |
| 动作判断不准 | `motion_frames` 加到 3，或让间隔更长（代码里 `grab_for_reply(interval=…)`） |
