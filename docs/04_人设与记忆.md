# 人设、音色、记忆

默认人设在 `persona/default.md`。它是当前源数据库默认人设的独立文本导出，原始文本 3350 字，未带聊天记录。
替换时编辑该文件，电话进程重启后读取；AstrBot 需要在面板同步导入并绑定到对应会话。

AstrBot 的聊天和记忆数据位于 `runtime/AstrBot/data`。这些文件不属于源码，也不会随项目分享。
电话直连模式只保留该进程自己的对话上下文；不应据此宣称电话自动拥有跨天 QQ 记忆。

默认声音由参考录音、参考文字、上游 GPT 权重和微调 SoVITS 权重共同决定。
替换为自己的 5～10 秒干净人声时，应同步修改 `paths.voice_ref`、`voice.prompt_text`、语言和必要的模型配置，并重新试听。
仅换录音未必能在当前微调模型上获得满意的新音色；需要时按上游指南制作自己的模型或使用通用底座。

先执行 `install/50_stop_all.bat` 停用本安装，再处理本地记忆；保留需要的备份后用 AstrBot 的会话/数据管理功能清理。
清空聊天数据是不可逆的数据操作，不作为普通部署步骤自动执行。
