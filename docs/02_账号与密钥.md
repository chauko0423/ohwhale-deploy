# 账号与密钥

| 服务 | 申请入口 | 本地位置 | 本版检查范围 |
|---|---|---|---|
| DeepSeek | [开放平台](https://platform.deepseek.com/) | `.env` 的 `DEEPSEEK_API_KEY`；AstrBot 提供商也需填写 | 阶段 3 只检查非空；实际请求验证可用性 |
| DashScope | [百炼控制台](https://bailian.console.aliyun.com/) | `.env` 的 `DASHSCOPE_API_KEY` | 录音识别/截图请求另行验证 |
| AstrBot | 本机面板 | `.env` 的 `ASTRBOT_DASHBOARD_PASSWORD` 与面板实际密码一致 | 桥接登录时验证，不内置密码 |
| QQ | 使用者自己的客户端 | 扫码后的客户端本地数据 | 人工确认上线，再测收发 |
| B 站 | 插件扫码登录 | `data/bilibili` | 登录态只留本机 |

模型名称以当前配置和账号权限为准。项目整理时核对的 [DeepSeek 官方模型页](https://api-docs.deepseek.com/quick_start/pricing/)列有 `deepseek-flash` 及图像理解能力；这不代表任意旧模型或第三方中转接口也支持。

默认电话截图使用 `llm.screen`，视频图版使用 `llm.vision`，文字使用 `llm.chat`，三者可分别改。
有密钥不等于余额、模型权限和地区均有效；`GET /models` 成功也不能证明可付费调用所有功能。

云端克隆音色属于账号配置，不携带原作者 voice ID。使用自己的授权录音在服务商处建立音色，配置到 AstrBot 后再填 `voice.cloud_provider_id`。
