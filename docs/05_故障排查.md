# 按症状排查

| 现象 | 先查 | 再查 |
|---|---|---|
| 安装脚本找不到 Python | `python --version`，确认不是 Windows 商店占位符 | Python 3.12+ 是否加入 PATH |
| 下载始终失败 | JSON 中具体文件、网络、预期 SHA256 | 文件放置位置；`.part` 可续传，不能直接改名冒充成功 |
| 启动报端口占用 | 是否已有安装在运行 | 用另一组完整配置或人工停止原实例；安装器不会代杀 |
| 没有 QQ 回复 | 客户端是否登录、OneBot 两端是否连接 | AstrBot 提供商、人设、白名单和管理员配置 |
| 接通但听不到人 | call_loop 心跳 | QQ 播放端点是否与实际监听一致 |
| 她说话但对方听不见 | TTS 输出的虚拟播放端点 | QQ 麦克风是否选虚拟录音端点 |
| 语音偶发变文字 | 本地合成日志、音频长度检查 | 自己账号的云端克隆提供商是否配置 |
| 画面黑屏 | CameraEmulator 驱动、QQ 摄像头选择 | 渲染进程、共享内存及 UDP 口型端口 |
| 图在但表情发不出 | `assets/stickers/index.json` 文件引用 | 目标会话与 AstrBot 平台状态 |
| B 站巡检不启动 | `features.bilibili`、master 三项 | 自己的登录态、任务/额度配置 |
| 重复语音回复 | AstrBot 内置 TTS 是否关闭 | voice_picker 是否重复安装 |
| verify 阶段 6 失败 | 是否完成真实测试并填记录 | 不能用旧机器结果或虚构数据补空项 |

日志保存在当前安装的 `logs`。反馈问题时提供脚本名、版本、脱敏错误和复现步骤；不要上传整份运行目录。
预览版的 `avatar_server.py` 和旧版 `avatar.py` 是实验/兼容路径，不是默认动态形象路径。
