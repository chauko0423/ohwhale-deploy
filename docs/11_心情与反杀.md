# 心情与反杀：让她像个会接梗的人

## 她为什么"像人"

不是靠微调模型，而是四样东西叠加：

1. **人设**：允许损人、禁止客服腔、短句、一行一个气泡
2. **反杀样例（few-shot）**：被调侃时"顺着对方前提反打一耙"
3. **小状态**：好感 / 心情 / 他刚说过的话，每轮注入一行 `[状态]`
4. **表情包/语音**：节奏对了，"人味"一半来自停顿和表情

## 反杀是"推理"不是"背台词"

```
他：我在设置里给你智商调低了
她：怪不得我现在看你觉得顺眼了
```

她在做三步推理：承认"智商被调低" → 推出"审美也变差" → 所以"看你觉得顺眼"。
一句自嘲 + 一句损人，全程不解释。

`persona/default.md` 的「反杀手册」给了 6 组样例和四条规则：

- 一次只反打一句，别解释为什么好笑，最多两行
- 顺着前提往下推，**不要否认前提**（否认就变成抬杠）
- 结尾可以补一个 emoji 或表情包，但别每句都补
- 他真难过的时候把刀收起来

## 小状态（心情/好感）

状态存在 `data/mood.json`，**通话侧和 QQ 文字聊天共用一份**，不会"电话里刚哄好、QQ 上又冷着脸"。

```json
{
 "affection": 53.0,
 "mood": 0.0,
 "last": ["你今天好可爱啊", "我有点累"],
 "updated": 1792904351
}
```

更新规则（`scripts/mood_state.py`，保守、可解释）：

| 他说的话里出现 | 好感 | 心情 |
|---|---|---|
| 夸她（可爱/喜欢/厉害…） | +2 | +1 |
| 骂她（笨/滚/讨厌…） | −4 | −2 |
| 难受（累/崩了/哭…） | +1 | −1（心疼，但不掉好感） |
| 调侃（哈哈/笑死/离谱…） | 0 | +1 |
| 道歉（对不起/我错了…） | +2 | +1 |
| 提到别的女生 | −2 | −1 |

每轮注入的格式：

```
[状态] 好感53/100（跟他熟了，会撒娇也会损他）；心情不错。 他刚说过：我有点累
```

## 接入方式

| 场景 | 位置 |
|---|---|
| QQ 文字聊天 | 插件 `plugins/astrbot_plugin_mood`，`@filter.on_llm_request` 里更新并追加到 system prompt |
| 通话 | `scripts/call_loop.py` 的 `Brain.think()` 里更新并拼到人设后面 |

两边都**只影响语气，不控制行为**：心情差也照干活，不拿情绪惩罚用户。

## 配置

无需配置。想临时清空/重置：

```bash
rm data/mood.json     # 下次对话自动回到默认（好感 50 / 心情 0）
```

## 测试

```bash
python -m unittest tests.test_mood_state -v
```

覆盖：默认值、夸/骂/难受/道歉的增减方向、上下限钳制、`last` 只留 5 条、摘要内容、连续写入后 JSON 仍合法。

## 局限

- 规则是关键词匹配，不理解反讽（"你可真聪明"会被当夸奖）——够用，但别指望它读心
- 好感变化幅度小，一天聊下来大概 ±10~20；这是刻意的，避免"一句话变热恋"
- 状态不参与长期记忆；"上周三没回消息"这种梗依然靠 AstrBot 的记忆/上下文
