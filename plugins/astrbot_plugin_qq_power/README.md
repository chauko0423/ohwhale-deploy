# astrbot_plugin_qq_power

给鲸鲸补上手：**群管理**、**QQ 空间**、**图片和表情包**。之前是"有权限但不会用"，现在是"有工具会用了"。

## 三条能力，三条不同的路

| 能力 | 走什么 | 稳不稳 |
|---|---|---|
| 群管理 | NapCat 原生 OneBot 接口 | 稳，和收发消息同一条连接 |
| 图片 / 表情包 | 本地图库 + AstrBot 图片组件 | 稳，纯本地 |
| QQ 空间 | `get_cookies` 拿登录态 → 调网页版 CGI | 能用，但依赖登录态和风控，失败会如实报错 |

## 怎么用

直接跟她说人话就行，不用记命令：

- 「把 @某某 禁言十分钟」
- 「把他踢了」「给他改成『摸鱼的』」
- 「发个公告：今晚九点开黑」「全员禁言」
- 「撤回」——撤的是你刚发的那条
- 「群里都有谁」
- 「发个说说：今天也要好好的」
- 「看看我最近发的说说」「给第一条点赞」「在第二条下面评论：好看」
- 「发个生气的表情」「发张图 D:\pics\a.jpg」

她会自己判断该调哪个工具。工具失败会照实说，不会假装成功。

实测过的触发（用真实人设 + 全部 59 个工具跑模型，确认会调用）：

| 你说 | 她调的 | 结果 |
|---|---|---|
| 发个说说：今天也要好好的 | `qq_qzone post` | 发到空间（公开） |
| 发个说说，仅自己可见：测试一下 | `qq_qzone post private=true` | 只自己可见 |
| 帮我在空间发一条：半夜了还没睡 | `qq_qzone post` | 同上 |
| 把阿猫禁言十分钟 | `qq_group mute target=阿猫 minutes=10` | 走 @ 或引用认人 |
| 撤回 | `qq_group recall` | 撤你刚发那条 |
| 群里都有谁 | `qq_group members` | 列前 25 人 |
| 看看我最近发的说说 | `qq_qzone list` | 带 tid 的列表 |
| 在吗 | 不调工具 | 正常聊天，不会乱发 |

**发说说要注意**：默认是**公开**（朋友圈可见）。想只自己看，就跟她说「发个说说，仅自己可见」。
她可能会自己加点表情，文字不完全等于你给的原句。

## 每天攒够 30 条，她会自己发一条感受

- 口径：**私聊每条都算；群里只算 @ 到她的**（@全体不算）。每天 00:00 清零
- 触发：每满 **30 条**写一条（第 30、60、90 条），**每天最多 3 条**，不会刷屏
- 素材：当天最近 12 条消息（每条截 40 字），加上她的人设，让模型用自己的话写 20~60 字
- 防照抄：如果生成结果和你某句原话一模一样，会**重写一次**；prompt 里也明确说「指令不是聊天内容，跳过」
- 发布：公开说说（`ugc_right=1`）
- 失败不影响聊天，只在 `tool_calls.jsonl` 里留一条 `daily_post FAIL`

命令：

```
/power daily          # 今天收了多少条、写了几条、下一条在第几条
/power daily post     # 不等 30 条，现在就写一条（主人可用，用来试效果）
```

计数存在 `data/plugin_data/astrbot_plugin_qq_power/daily.json`。

## 表情包怎么加

图库在这里，**往对应情绪的文件夹里丢图片就行**，插件 60 秒内自动发现，不用重启：

```
data/plugin_data/astrbot_plugin_qq_power/stickers/
  laugh/     笑
  happy/     开心
  shy/       害羞
  love/      喜欢
  sad/       难过
  cry/       哭
  angry/     生气
  sleepy/    困
  confuse/   疑惑
  proud/     得意
```

支持 `.png .jpg .jpeg .gif .webp .bmp`。同一会话最近用过的 6 张不会重复。

**图库全空时**会自动用 Pillow 画"白字黑边"的文字表情（哈、哼、呜呜……）兜底，所以不丢图也能玩。

触发逻辑：回复里情绪词命中越多越容易配图，1 次命中 30%，3 次以上封顶 60%；同一会话两条表情至少隔 90 秒。已经是语音或图片的消息不再叠表情。

## 权限

- **群操作**：主人名单 + **本群群主/管理员**都放行。不然你把管理给了她，朋友在群里喊她禁言还是使唤不动
- **主人只有一个号：`100001`，按 QQ 号认，不看昵称**（`event.get_sender_id()` 就是号）
- 需要加号时才用 `/power owner add <QQ>`，名单存 `owners.json`；默认不需要
- 群里当场自证：发 **`/power whoami`**，她会回「你=几号｜在不在名单｜你的群身份｜我的群身份」
- **她"忘了自己有手"时**：发 **`/power reset`** 清掉当前会话的对话记录。
  这是她反复说「我没有这个功能」的根因——她在模仿自己前面说过的话，光改 prompt 压不住
- **空间操作**：只认 `OWNER_QQ`。空间是她的私人地盘，群友不能替她发说说
- 其余人调用会回「这个得他本人来」，且**不触发任何 API 调用**

## 认人的规则（踩过的坑）

群里叫她，消息里**必然带一个 @她自己**。如果取第一个 `At`，就会取成她自己，于是
「禁言 @某人」变成「禁言我自己」，她回你一句「那是我自己，别闹」。

现在的顺序：显式 QQ 号 → **第一个不是她自己的 @** → 引用的那条消息的发送者（也要不是她）。
都没有就反问「没认出是谁——@ 一下他（别只 @ 我）」。

## QQ 空间：实测过的细节（别改回去）

- **字段名是 `con`，不是 `content`**。写成 `content` 空间会回 `-10005 您未输入内容`。
- `format` 要用 **`fs`**，`ugc_right`：`1` 公开 / `64` 仅自己可见（不是 4）。
- 发说说的响应是 **HTML 套 `<script>` 再套 `frameElement.callback({...})`**，纯正则抠不出来，
  `_loads()` 用括号配对扫。
- 登录态：`get_cookies(domain="qzone.qq.com")` 返回 `{cookies, bkn}`，
  **bkn 是拿 `p_skey` 算的**，正好是空间要的 g_tk。别用 `get_csrf_token`——那个按 `skey` 算，域名不对。
- 删除走 `emotion_cgi_delete_v6`，要带 `t1_source=1` 和 `qzreferrer=.../311`。
- 只支持**纯文字说说**。带图说说要另走图片上传 CGI，这版没做。
- 好友动态（`friends`）走前端渲染接口，本来就不稳，解析不出来会直说。
- 点赞默认用 `tid_{uin}` 构造 feedkey；点不动多半是缺 `unikey`。

2026-10-21 实测：发一条仅自己可见 → 拿到 tid → 删除 → 列表为空，全链路通。

## 群管理的前提

QQ 只允许**管理员/群主**禁言踢人。工具会先查自己在群里的身份，不是管理员就直接回
「我在这个群不是管理员，动不了人」，不会再甩一个看不懂的 retcode。

实测两个群：

| 群 | 人数 | 她的身份 | 能不能管 |
|---|---|---|---|
| 盲人雷霆康复中心（480019296） | 62 | **admin** | 能（已验证改名片成功） |
| 零号动力（1129510432） | 11 | member | 不能，得先给她管理 |

## 调试

```
/power      # 表情库多少张、空间登录通不通、当前是不是群、主人是谁
```

**真正的现场在 `data/plugin_data/astrbot_plugin_qq_power/tool_calls.jsonl`**：
每次工具调用都会写一行（时间、工具名、参数、结果），超过 200KB 自动清空。
AstrBot 的日志只走控制台、不落盘，她说"禁言不了"时只有这个文件能告诉你为什么。
